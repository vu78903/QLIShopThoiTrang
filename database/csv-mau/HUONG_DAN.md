# CSV mẫu

Nhập các file tại chức năng Nhập CSV của Đối tác hoặc Sản phẩm bằng tài khoản cửa hàng trưởng. Đây là dữ liệu mẫu chưa được nhập vào database.

- Sửa tên, số điện thoại, email, địa chỉ và mật khẩu mẫu trước khi nhập.
- File khách hàng có ngày sinh theo yyyy-MM-dd và giới tính Nam/Nữ.
- Mã đối tác và SKU để trống cho hệ thống tự sinh. Mã sản phẩm dùng mã chưa tồn tại nếu thêm sản phẩm mới.
- File sản phẩm có 3 sản phẩm, mỗi sản phẩm 3 màu. Đối chiếu loại sản phẩm và nhà cung cấp trong hệ thống trước khi nhập.
- Quần jeans dùng size số; phụ kiện dùng Free size. Tồn mẫu bằng 0.
- File UTF-8 BOM. Khi mở Excel, để cột điện thoại dạng Text để giữ số 0 đầu.
- Nhập chỉ thêm mới; trùng mã hoặc một dòng lỗi thì không lưu cả lượt.
